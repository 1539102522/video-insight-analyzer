# 🎬 智能短视频分析系统 —— 小白使用手册

> 一个"自动看懂短视频"的工具：你把视频丢进来，它帮你自动识别视频里在说什么、画面上有什么字、是什么内容，然后用 AI 帮你分类（歌曲 / 美食 / 美文 / 其他）并整理成歌单、菜谱、文案，最后存到本地文件夹里，随时可以搜、可以问 AI。

**完全不会编程也能用**，跟着下面的步骤一步一步做就行。本手册以 Windows 电脑为例（大多数人用 Windows）。

## 一、先搞清楚这是啥

整个系统干三件事：

```
你上传视频
   ↓
【第一层】专业模型自动"看"视频：
   - 语音识别：听视频里在说什么话、唱什么歌
   - 文字识别：看画面上有什么字（字幕、菜名、歌词）
   - 视觉理解：看画面是什么内容（食物？演唱会？风景？）
   - 音频检测：有没有背景音乐
   ↓
【第二层】AI 大模型（DeepSeek）把上面的信息"读懂"：
   - 判断这是哪类视频（歌曲 / 美食 / 美文 / 其他）
   - 提取出有用信息（歌名歌手 / 菜名食材步骤 / 文章作者）
   - 自动检查有没有出错，错了让它重新来
   ↓
存到本地文件夹，按类别分好类（outputs/歌曲、outputs/美食…）
```

你需要准备三样东西：
1. 一台电脑（Windows 最好，内存 8GB 以上，硬盘留 10GB 空间）
2. 一个 DeepSeek 的 API 密钥（AI 大脑的"门票"，后面教你免费/便宜申请）
3. 网络（能访问国内镜像即可）

## 二、第一步：安装 Python

Python 是整个程序运行的基础环境，**必须先装**。

1. 打开浏览器，访问 Python 官网下载页：
   **https://www.python.org/downloads/**
2. 点击黄色大按钮 **"Download Python 3.x.x"**（版本 3.10 ~ 3.13 都行，推荐 3.11 或 3.12）；
3. 下载完成后双击安装包，**关键一步**：勾选最下面的
   ✅ **"Add python.exe to PATH"**（把 Python 加入环境变量）
   **然后再点 Install Now**；
4. 等它装完。

**验证是否装好**：
1. 按键盘 `Win + R`，输入 `cmd`，回车，打开黑色命令窗口；
2. 输入下面这行，回车：
   ```cmd
   python --version
   ```
3. 如果显示 `Python 3.x.x`，说明装好了 ✅；如果提示"不是内部或外部命令"，说明第 3 步的勾选没勾，请重新装一遍。

## 三、第二步：下载项目代码

两种方式任选：

**方式 A：GitHub 下载 zip（推荐小白）**
1. 在 GitHub 仓库页面点绿色的 **"Code"** 按钮 → **"Download ZIP"**；
2. 下载后解压到你想放的位置，比如 `D:\智能项目`；
3. 注意：**解压路径最好全英文、无空格**（避免后面踩中文路径的坑）。

**方式 B：命令行 clone（会一点 git 的话）**
```cmd
git clone https://github.com/你的用户名/仓库名.git
cd 仓库名
```

## 四、第三步：安装依赖包

依赖包 = 程序要用到的一堆"零件库"，一条命令装完。

1. 打开命令窗口（`Win + R` → 输入 `cmd` → 回车）；
2. 进入项目目录。假设你解压到 `D:\智能项目`：
   ```cmd
   cd /d D:\智能项目
   ```
3. 执行安装命令（**用国内镜像，速度快**）：
   ```cmd
   pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
   ```
4. 耐心等它装完（可能要几分钟，看到没有红色报错就是成功）。

> 如果提示 `pip 不是内部或外部命令`，说明 Python 没装好或 PATH 没勾，回到第一步重装。

## 五、第四步：配置 AI 密钥

AI 密钥就像"钥匙"，让系统能调用 DeepSeek 大模型。

### 5.1 去申请密钥（很便宜，新用户一般送一点额度）

1. 打开 **https://platform.deepseek.com** ，注册/登录；
2. 左侧菜单点 **API Keys** → **创建 API Key**；
3. 复制那串 `sk-` 开头的密钥（**只显示一次，务必保存好**）；
4. （可选）在"充值"里充一点钱，比如 10 元，能用很久。

### 5.2 把密钥写进项目

1. 在项目文件夹里新建一个文件，名字就叫 `.env`（注意前面有个点，没有扩展名）；
   - 用记事本：右键 → 新建 → 文本文档 → 重命名为 `.env`（如果看不到后缀，先打开"文件资源管理器 → 查看 → 勾选'文件扩展名'"）；
2. 用记事本打开 `.env`，粘贴下面这行，把 `sk-你的密钥` 换成你刚才复制的那串：
   ```
   LLM_API_KEY=sk-你的密钥
   ```
3. 保存关闭。

> ⚠️ 这个 `.env` 文件已经被 `.gitignore` 排除，**不会**被上传到 GitHub，密钥是安全的。
> 没有密钥也能跑，但只能用"第一层证据提取"，不能分类、不能 AI 问答。

## 六、第五步：下载模型文件

模型 = 各专业识别的"大脑"，比较大（总共约 6GB），仓库里没放，需要你自己下。

> 大部分模型**第一次运行时会自动下载**，只是国内直连慢，建议先设置镜像加速（下面的 6.1）。ASR 的小模型（tiny/small）建议手动下载（更快、可提速）。

### 6.1 设置国内镜像（让下载不卡）

打开命令窗口，执行下面两条（每次开新窗口都要设一次，或写进系统环境变量）：

```cmd
set HF_ENDPOINT=https://hf-mirror.com
set HF_HUB_DISABLE_XET=1
```

> 更省事的办法：这两条加到系统环境变量里一劳永逸（右键"此电脑 → 属性 → 高级系统设置 → 环境变量 → 新建"，变量名 `HF_ENDPOINT`、值 `https://hf-mirror.com`；再新建 `HF_HUB_DISABLE_XET`、值 `1`）。

### 6.2 各模型说明（按需要下载）

| 模型 | 用途 | 大小 | 不下载会怎样 |
|------|------|------|-------------|
| faster-whisper-medium | 语音识别（最准） | ~1.5GB | ASR 不可用 |
| faster-whisper tiny/base/small | 语音识别（更快） | 75MB~483MB | 可选，用 medium 也能跑 |
| EasyOCR（中文） | 画面文字 | ~110MB | OCR 不可用 |
| CLIP ViT-B/32 | 视觉理解（轻量，默认） | ~338MB | 视觉不可用 |
| InternVL2-2B | 视觉理解（高质量 VLM，可选） | ~4.2GB | 可选，不用 VLM 就跳过 |

### 6.3 最省事的做法：让程序自动下载

只要做了 6.1 的镜像设置，直接启动系统（第七步），第一次跑的时候它会自动下载缺的模型（会提示"首次运行需下载模型，请耐心等待"）。

### 6.4 手动下载 ASR 小模型（推荐，能大幅提速）

在项目 `models/` 目录下分别建 `faster-whisper-tiny`、`faster-whisper-base`、`faster-whisper-small` 三个文件夹，每个文件夹里放 4 个文件。以 tiny 为例，用浏览器分别打开并下载（保存到对应文件夹）：

```
https://hf-mirror.com/Systran/faster-whisper-tiny/resolve/main/model.bin
https://hf-mirror.com/Systran/faster-whisper-tiny/resolve/main/config.json
https://hf-mirror.com/Systran/faster-whisper-tiny/resolve/main/tokenizer.json
https://hf-mirror.com/Systran/faster-whisper-tiny/resolve/main/vocabulary.txt
```

（base / small 同理，把网址里的 `tiny` 换成 `base` / `small`）

## 八、第七步：上传第一个视频试试

1. 在网页上，你会看到"📤 上传并分析"区域；
2. 点击虚线框，选择你电脑里的一个视频（MP4 最好）；
3. 直接点 **🚀 开始分析**；
4. 等待：下方会显示进度和日志，完成后顶部出现绿色提示"✅ 分析完成：xxx（类别：xxx）"，并且视频可以播放；
5. 往下滚动，在"🕘 历史记录"里点"展开"，能看到刚分析的视频，点"查看"看完整分析详情（分类理由、提取出的歌名/菜谱/文案、信息出处、质检过程）。

> 第一次跑会先下载模型，会比较久（几分钟），之后就快了。

## 九、进阶：批量上传和加速

### 批量上传

1. 在"上传并分析"标题右侧，点 **"批量上传"** 按钮切换模式；
2. 一次选择多个视频（或把整个文件夹的视频拖进去）；
3. 点开始分析，它会排队逐个/并行分析，每个视频显示进度（排队中 → 分析中 → ✅完成）；
4. 完成后所有视频按类别自动归档到 `videos/<类别>/` 和 `outputs/<类别>/`。

### 加速（打开"⚙️ 高级参数"）

- **📌 推荐搭配**（一键设置）：
  - ⚡ **极速**：适合一次传几十上百个视频，速度快；
  - ⚖️ **均衡**（默认）：速度质量兼顾，日常用这个；
  - 🎯 **高质量**：追求准确，会切换更慢但更准的 VLM 视觉模型；
- 系统会**自动检测你电脑的配置**（几核 CPU、多少内存），线程数、并行数自动推荐；
- 想手动调：ASR 规格选 tiny/small 更快、束宽选 1 最快、抽帧间隔调大、OCR 最长边调小；
- 每个参数旁边的 ❓ 点一下都有解释；
- 内存不够时，可**关闭"多线程并行分析"**开关，改成一个个来。

## 十一、常见问题（FAQ）

**Q1：提示"端口被占用"或打不开网页？**
换一个端口启动：`python web_ui.py --port 8801`，然后访问 http://127.0.0.1:8801

**Q2：`python` 或 `pip` 提示"不是内部或外部命令"？**
Python 没装好或安装时没勾选 "Add to PATH"，回到第一步重装。

**Q3：pip 安装很慢或失败？**
换镜像再试：
```cmd
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**Q4：模型下载一直卡住/失败？**
确认设置了镜像（6.1 节），或者用浏览器手动下载（6.4 节）。

**Q5：分析时报 `[402] You have run out of balance`？**
DeepSeek 账户余额用完了，去 platform.deepseek.com 充值，或换个有余额的密钥填进 `.env`。

**Q6：上传的视频在网页里黑屏播放不了？**
视频是 HEVC 编码，浏览器不支持；系统会自动转成 H.264，稍等片刻再播放即可。

**Q7：视频没有声音，ASR 没结果？**
正常——没有音轨的视频会自动跳过语音识别。

**Q8：批量分析时电脑很卡/内存不足？**
关闭"多线程并行分析"开关，或把 ASR 规格改小（tiny/small）、调大抽帧间隔。

**Q9：路径里有中文会不会出问题？**
本项目已做了中文路径兼容处理；如果仍报错，把整个项目移到纯英文路径（如 `D:\project`）。

**Q10：分析结果保存在哪？**
`outputs/<类别>/` 下有 JSON 和 MD 报告，`videos/<类别>/` 下是分类好的视频。
